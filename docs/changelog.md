# История изменений

## 1.0.1

- Эндпоинт `GET /users/count` — количество пользователей с учётом поиска.

## 1.0.0

- Поиск пользователей по имени и email (`GET /users?search=`).
- Пагинация списка пользователей (`limit`, `offset`).
- Документация проекта на MkDocs с автогенерацией API Reference.

## 0.1.0

- CRUD-операции над пользователями.
- Проверка уникальности email.
